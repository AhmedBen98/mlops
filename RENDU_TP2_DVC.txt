ÉTAPE 4 : Ajouter le fichier iris.csv à DVC
================================================================================

Script de génération (generate_iris.py) :
------------------------------------------
from sklearn.datasets import load_iris
import pandas as pd

# Load iris dataset
iris = load_iris(as_frame=True)
# Create DataFrame
df = iris.frame
# Rename 'target' column to 'species'
df = df.rename(columns={'target': 'species'})
# Save to CSV
df.to_csv("data/iris.csv", index=False)
print("iris.csv generated successfully")

Exécution :
-----------
python generate_iris.py

Ajout à DVC :
-------------
dvc add data/iris.csv

Résultat :
----------
 Fichier iris.csv généré (151 lignes : 1 en-tête + 150 données)
 Fichier data/iris.csv.dvc créé

COMMANDES PRINCIPALES UTILISÉES

Initialisation :

-------------------------

Pipeline :
----------

dvc repro

Remote DVC :
------------
dvc remote add -d myremote /tmp/dvc-storage
dvc push
dvc pull

Restauration :
--------------

dvc checkout
